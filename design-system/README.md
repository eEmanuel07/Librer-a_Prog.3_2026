## Por qué `off`

El proyecto es una **API REST sin pantallas** (FastAPI). La consigna del parcial no pide interfaz: los casos se prueban con archivos `.http` y `psql` (ver `knowledge-base/06_funcionalidades.md`). No hay marca, colores ni componentes que definir.

## Qué significa para los changes

- Ningún change pide mockups ni revisión visual. En el `design.md` de cada change va `## UI Mockups` con `Decision: no (project policy)`.
- Esta decisión es de todo el proyecto: no se vuelve a preguntar en cada `/opsx:propose`.
- Sólo un pedido explícito del grupo la cambia. Si algún día hubiera pantallas, se vuelve a correr `/active-orchestrator:design` y se elige `system-and-mockups` o `system-only`.
